# Which Methods Should I Use?
With all these methods available, the question arises: **Which methods should I use?** The answer is: it depends on what you are learning, as Cornell notes cannot be applied to procedural skills like solving a math problem, nor can a worked example be applied to purely conceptual knowledge. So, ask yourself the following 2 questions: Does it require **theoretical knowledge**? and Does it require **problem-solving**? Let's look at some examples:

| Field | Requires Theoretical Knowledge? | Requires Problem-Solving? |
| --- | --- | --- |
| Mathematics | Yes | Yes |
| Programming | Yes | Yes |
| Medicine | Yes | Yes |
| Philosophy | Yes | No (except for logic) |

Here are the methods categorized by requirements:

| Requirement | Methods |
| --- | --- |
| Used regardless<br>of requirement | Elaborative interrogation <br>Self-explanation <br>Spaced retrieval practice <br>Wakeful rest |
| Theory | Cornell notes<br>Questionable:<br>- Highlighting <br>- Rereading |
| Problem-solving | Interleaved practice <br>Worked examples |
