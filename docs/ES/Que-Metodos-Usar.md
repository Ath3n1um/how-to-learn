# ¿Qué métodos debo utilizar?
Ya con todos estos métodos nos surge la pregunta: **¿Qué métodos debo utilizar?** Y la respuesta es: depende de qué estés aprendiendo, pues no es que sea posible aplicar las notas Cornell a la habilidad procedimental de resolver un problema matemático o un ejemplo resuelto al conocimiento conceptual. Entonces, hazte las siguientes 2 preguntas: ¿Requiere **conocimiento teórico**? y ¿Requiere **resolución de problemas**? Veamos unos ejemplos:

| Área         | ¿Requiere conocimiento teórico? | ¿Requiere resolución de problemas? |
| ------------ | ------------------------------- | ---------------------------------- |
| Matematicas  | si                              | si                                 |
| Programación | sí                              | sí                                 |
| Medicina     | sí                              | sí                                 |
| Filosofía    | Sí                              | No (a excepción de la lógica)      |
Aquí están los métodos por requerimiento:

| Requiere                                | Métodos                                                                                                          |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Usados sin importar<br>El requerimiento | Elaboración interrogativa  <br>Auto explicacion  <br>Práctica de recuperación espaciada  <br>Descanso en vigilia |
| Teoría                                  | Notas Cornell<br>Cuestionabes:<br>- Resaltar con marca texto  <br>- Relectura                                    |
| Resolución de problemas                 | Practica Intercalada  <br>Ejemplos resueltos                                                                     |
